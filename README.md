# Armario · ofertas que combinan

Web instalable (PWA) que:

- Aprende tu **perfil de color** a partir de fotos de conjuntos que llevas.
- **Escanea prendas** tuyas (foto o código de barras), detecta su color y te dice qué comprar para combinarlas, con teoría del color (neutros, análogos, complementarios, tono sobre tono, regla 60-30-10).
- Abre la búsqueda exacta en **Zara, Bershka, Pull&Bear, Zalando y JD Sports**, y un buscador de **solo ofertas** en todas las tiendas.

Todo se analiza en el propio móvil; las fotos no salen de él.

- Para publicar una versión nueva, sube `APP_VERSION` en `index.html` y `VERSION` en `sw.js`.
- Las URLs de búsqueda de cada tienda están en `STORES` dentro de `index.html`.
